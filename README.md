# EDAB2724 Assignment 1: Bayesian Networks

## Overview
This assignment explores Bayesian Networks using subsistence retail consumer data to understand relationships between variables and perform probabilistic reasoning.

## Key Activities
- Perform Exploratory Data Analysis (EDA).
- Analyse relationships using Pearson correlation and heatmaps.
- Build an expert-defined Bayesian Network.
- Learn a network structure using Hill Climbing and BIC.
- Perform probabilistic inference and compare network structures.

## Tools and Technologies
Python, Jupyter Notebook, pandas, NumPy, bnlearn, SciPy, Matplotlib and Seaborn.

## Learning Outcomes
Develop practical skills in probabilistic modelling, Bayesian inference and comparing expert knowledge with data-driven learning.
